2. Для изменения реквизитов продукта.

Пример patch-json:

{
    "products":[
        {
            "id": "a4cdb69d-a097-11f1-b717-f4ce23e7b728",
            "name": "Изменение наименования"
        }
    ]
}

Ответ json:

{
    "success": true,
    "message": "",
    "data": []
}

Если будут ошибочные записи документов, их гуиды будут в списке data (массив GUID-ов документов)
